# Архитектура проекта `crusher-parts-frontend`

## 🧱 Общая концепция

Фронтенд-проект построен на **React + Vite**, и использует **универсальный механизм отображения и управления таблицами**, включая:

- редактирование, добавление, удаление записей;
- импорт данных из Excel;
- просмотр истории изменений;
- централизованную конфигурацию колонок.

---

## ⚙️ Технологический стек

- **Бандлер**: Vite
- **Фреймворк**: React
- **UI-библиотека**: MUI (Material UI)
- **Drag & Drop**: `@dnd-kit`
- **Состояние**: React Context API
- **HTTP**: Axios
- **Работа с таблицами**: кастомная реализация с `EditableRow` и `BaseTable`

---

## 📁 Структура `src/`

### `components/`
- `common/`: универсальные компоненты таблиц — `BaseTable`, `EditableRow`, `ActionIcons`, `CollapseCell`.
- `users/`, `clients/`, `roles/`: специализированные таблицы для конкретных сущностей.
- `dialogs/`, `modals/`: `ImportModal`, `FullHistoryDialog`.

### `hooks/`
- `useTableData`: универсальный хук для загрузки, добавления, редактирования и удаления данных с сервера.

### `config/`
- `fieldSchemas.js`: централизованное описание колонок таблиц по типу данных.

### `context/`
- Глобальное состояние, включая вкладки и пользовательские контексты.

### `pages/`
- Роутинговые компоненты, например `UsersPage.jsx`.

### `api/`
- `axiosInstance`: конфигурированный Axios-клиент.

### `utils/`
- Утилиты: `sanitizePayload`, `transliteration`, `confirmAction` и пр.

---

## 📊 Универсальная таблица

Компонент `BaseTableWrapper` — основной элемент для вывода и управления таблицами.

**Состав:**
- `useTableData` — управляет состоянием, CRUD, фильтрацией, пагинацией.
- `BaseTable` — визуализация таблицы.
- `EditableRow`, `EditableCell` — интерактивные строки редактирования.
- `ActionIcons` — действия: редактировать, удалить, история.
- Поддержка: `withImport`, `withLogs`, `pagination`.

---

## 🔌 API и взаимодействие с сервером

- Все данные загружаются через REST API.
- Форматы запросов:
  - `GET /resource`
  - `POST /resource`
  - `PUT /resource/:id`
  - `DELETE /resource/:id`
- `sanitizePayload()` очищает виртуальные поля (например, `actions`, `isEditing`) перед отправкой.
