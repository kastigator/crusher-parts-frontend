## 📘 Архитектура таблиц в проекте `crusher-parts`

Документ фиксирует полную структуру создания таблиц и объясняет, как использовать существующие файлы и компоненты.

---

### ✅ Ядро таблиц (не трогать, работает стабильно)

| Файл               | Назначение                                 |
| ------------------ | ------------------------------------------ |
| `BaseTable.jsx`    | Универсальная таблица                      |
| `EditableRow.jsx`  | Строка таблицы в режиме редактирования     |
| `EditableCell.jsx` | Ячейка таблицы (редактирование / просмотр) |
| `ActionIcons.jsx`  | Кнопки действий в строке                   |

---

### 🧠 Централизация полей

| Файл                  | Назначение                                                   |
| --------------------- | ------------------------------------------------------------ |
| `fieldSchemas.js`     | Описание всех доступных полей (type, title, required и т.п.) |
| `fieldRenderers.jsx`  | Как отображать и редактировать значение по типу              |
| `tableDefinitions.js` | Какие поля входят в каждую таблицу                           |

**Пример использования:**

```js
export const usersTableColumns = [
  { field: 'username', ...userFields.username },
  { field: 'email', ...userFields.email },
  { field: 'role_slug', ...userFields.role_slug },
]
```

### 🔁 Хуки и API

| Файл               | Назначение                                             |
| ------------------ | ------------------------------------------------------ |
| `useTableData.jsx` | Загружает данные, обрабатывает onAdd, onSave, onDelete |
| `useRoles.js`      | Загружает роли для выпадающих списков                  |

### 📄 Страницы и структура

Каждая вкладка оформляется так:

| Файл             | Назначение                                 |
| ---------------- | ------------------------------------------ |
| `UsersPage.jsx`  | Страница, подключающая вкладку             |
| `UsersMain.jsx`  | Контейнер: размещает таблицы, кнопки       |
| `UsersTable.jsx` | Компонент таблицы (подключает `BaseTable`) |

## 🔨 Шаблон создания новой таблицы

1. 📘 В `fieldSchemas.js` описать поля
2. 📋 В `tableDefinitions.js` собрать `columns`
3. 🧩 В `UsersTable.jsx` или аналог — подключить `useTableData` и `BaseTable`
4. 📄 В `UsersMain.jsx` — разместить таблицу
5. 📂 В `UsersPage.jsx` — подключить `UsersMain`

Готово ✅ Таблица будет поддерживать:

* добавление, редактирование, удаление
* required-поля
* выпадающие списки
* отображение истории изменений (если передан `onShowLogs`)
* строку добавления
* подтверждение удаления

---

## 📎 Рекомендации

* Не редактировать `BaseTable`, если не уверен
* Добавлять поля **только** в `fieldSchemas.js`
* Использовать `fieldRenderers` вместо ручного `display` / `editor`
* Все таблицы обязаны использовать `tableDefinitions.js`
* Если поведение уникальное (иконки, drag’n’drop) — делай локально в таблице
* Для импорта использовать `ImportModal` и схему из `entitySchemas`
