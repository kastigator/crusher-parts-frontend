# ActionIcons.jsx — иконки действий в строке

## Назначение
Рендерит кнопки (иконки) действий над строкой:
- Удалить
- Редактировать ✏️
- История изменений 🕘
Компонент больше не отвечает за сохранение или отмену — эти действия выполняет `EditableRow`.

## Пропсы
| Название | Назначение |
|----------|------------|
| row | Объект строки |
| onEdit(row) | Нажатие на ✏️ |
| onDelete(row) | Удалить запись |
| onShowLogs(row) | История изменений |
| iconSize | Размер иконок (опционально) |

## Поведение
Отображает только те иконки, для которых переданы функции. Обычно используются ✏️, 🗑 и 🕘.
