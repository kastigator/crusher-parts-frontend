# ActionIcons.jsx — иконки действий в строке

## Назначение
Рендерит кнопки (иконки) действий над строкой:
- Сохранить
- Отменить
- Удалить
- Редактировать ✏️
- Сброс пароля 🔐
- История изменений 🕘

## Пропсы
| Название | Назначение |
|----------|------------|
| isEditing | В режиме редактирования? |
| isNewRow | Это строка добавления? |
| row | Объект строки |
| onSave / onAdd / onDelete / onCancel | Обработчики |
| onResetPassword / onShowLogs / onEdit | Спец-действия |

## Поведение
- В режиме редактирования: 💾, ✖
- В обычном режиме: ✏️, 🗑, 🔐, 🕘 (если переданы функции)
